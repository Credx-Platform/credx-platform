How the platform operates today

The current architecture separates web and API deployment targets while keeping optional providers outside the core health check.

Browser -> CredX Web -> static pages, portal assets, and `/api/*` proxy
CredX API -> Prisma -> PostgreSQL
CredX API -> Resend / SendGrid / SMTP for email
CredX API -> Stripe / PayPal for billing paths
CredX API -> Vercel Blob for private document storage where configured
CredX API -> AI Gateway / Anthropic for AI-assisted features
CredX - Credit Intelligence & Financial Readiness Platform. Optional professional support is separate from the core software workspace.
