# Business Classification

## CURRENT

CredX currently has both software-platform characteristics and credit-service workflows.

Software indicators:

- Own web application and API.
- User accounts and authenticated dashboard.
- Education modules and quiz/progress tracking.
- Credit-report upload and analysis workflows.
- Generated reports and action guidance.
- Admin CRM and operational workflows.
- Payment integration and recurring-payment fields.

Service indicators:

- Contract and CROA-oriented workflows.
- Dispute-letter generation and mailing support.
- Staff/admin review flows.
- Client status values tied to service fulfillment.

## TARGET POSITIONING

CredX should be positioned as:

Credit Intelligence & Financial Readiness Platform

Optional credit-related support should be described separately as professional support or education, not as the core product identity.

## NAICS EVALUATION

Candidate: NAICS 513210 - Software Publishers.

Support improves as CredX increases subscription software revenue, self-service platform value, user-owned dashboards, SaaS entitlements, B2B licensing, analytics, and reusable software workflows.

## REMAINING WEAKNESSES

- SaaS plans and entitlements are not centralized.
- B2B organization model is not implemented.
- Some public copy may still read service-first.
- Human support remains tightly coupled to parts of the workflow.

Legal/accounting classification should be reviewed by qualified counsel or tax advisors before external claims are made.
